🔐 Xác thực (Authentication)

API sử dụng xác thực bằng Bearer Token. Liên hệ Admin NathaMedia để nhận API Key.

URL CƠ SỞ (BASE URL)
https://nathamedia.net/api
Hoặc localhost: http://localhost:8080/api
Lấy API Key — Sử dụng phần quản lý API key ở phía trên hoặc liên hệ Admin.
Thêm vào Header — Bao gồm các headers sau trong mọi request:
Authorization: Bearer <api-key-của-bạn>
Content-Type: application/json
📌 Response format chuẩn: Tất cả response đều có dạng {"success": true, "data": {...}} hoặc {"success": false, "error": "...", "code": 400}

POST /veo/account-session Lấy token + project_id của Veo account được gán ›

Endpoint này dùng cho worker/client bên ngoài cần lấy trực tiếp token và project_id của tài khoản Veo đã được gán theo API key.

📌 Logic chống trùng account:
Nếu user đã có Veo account được gán thì gọi lại sẽ vẫn trả đúng account đó.
Nếu user chưa có account thì hệ thống tự lấy 1 account active còn rảnh và gán cố định cho user đó.
User khác gọi bằng API key khác sẽ không lấy trùng account đã gán.
HeaderTypeMô tả
X-API-KeyrequiredstringAPI key của user cần lấy session
Content-Typeoptionalstringapplication/json
Request Body
{}
Response (200)
{
  "success": true,
  "data": {
    "token": "ya29.xxx",
    "project_id": "project_xxx",
    "account_name": "Account 1"
  }
}
Response lỗi
{
  "success": false,
  "error": "No active free Veo account is available",
  "code": "NO_AVAILABLE_ACCOUNT"
}
📌 NO_AVAILABLE_ACCOUNT: không còn Veo account active rảnh để gán.
📌 SESSION_UNAVAILABLE: account đã gán nhưng không lấy được token hoặc project_id.
📌 Có thể dùng Authorization: Bearer API_KEY, nhưng endpoint này khuyến nghị dùng X-API-Key.
cURL Example
curl -X POST "https://nathamedia.net/api/veo/account-session" \
  -H "X-API-Key: {{token}}" \
  -H "Content-Type: application/json" \
  -d '{}'
Code Demo (JavaScript)
async function getVeoAccountSession() {
  const response = await fetch('https://nathamedia.net/api/veo/account-session', {
    method: 'POST',
    headers: {
      'X-API-Key': API_KEY,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({})
  });

  const result = await response.json();
  if (!result.success) throw new Error(result.code || result.error);

  const { token, project_id } = result.data;
  console.log('Veo token:', token);
  console.log('Project ID:', project_id);
  return result.data;
}

Code Demo (JavaScript)
async function textToVideo() {
  const response = await fetch('https://nathamedia.net/api/veo/text-to-video', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      project_id: 'uuid-project',
      name: 'testing',
      model: 'VEO_3.1_FAST',
      screen_ratio: '16:9',
      prompts: ['A cat walking in the rain']
    })
  });
  const result = await response.json();
  const taskId = result.data.id;

  // Polling: gọi GET /api/veo/video?task_id=... mỗi 10s
  const poll = setInterval(async () => {
    const status = await fetch(
      `https://nathamedia.net/api/veo/video?task_id=${taskId}`,
      { headers: { 'Authorization': `Bearer ${API_KEY}` } }
    ).then(r => r.json());

    console.log('Status:', status.data.status);
    if (status.data.status === 'COMPLETED' || status.data.status === 'FAILED') {
      clearInterval(poll);
      if (status.data.status === 'COMPLETED') {
        console.log('Download:', `https://nathamedia.net/api/veo/download/${taskId}`);
      }
    }
  }, 10000);
}

GET /veo/download/:task_id Tải video/ảnh khi COMPLETED ›

Khi task có status: "COMPLETED", gọi endpoint này để tải file trực tiếp.

📌 Xác thực qua Header: Authorization: Bearer API_KEY
📌 Nếu media_id là URL → server trả redirect 302 đến URL đó.
📌 Nếu media_id là file local → server trả file trực tiếp (video/mp4).
📌 Nếu task đang PENDING/PROCESSING → trả HTTP 202 với {"success": false, "error": "Task is still PROCESSING..."}
📌 Nếu task FAILED → trả HTTP 422 với {"success": false, "error": "Task failed: ..."}
cURL Example
# Download khi task COMPLETED
curl -o video.mp4 "https://nathamedia.net/api/veo/download/TASK_ID" \
  -H "Authorization: Bearer API_KEY" \
  -L
📌 Flag -L để curl tự động follow redirect (khi media_id là URL).
POST /veo/generate ⚡ All-in-one: Auto tạo project + task ›

Endpoint đơn giản nhất — chỉ cần gửi prompt. Tự động tạo project nếu không truyền project_id. Trả về poll_url và download_url sẵn.

FieldTypeMô tả
promptrequiredstringPrompt tạo video
project_idoptionalstringUUID project (bỏ qua = tự tạo mới)
modeloptionalenumMặc định: VEO_3.1_FAST
screen_ratiooptionalenum16:9 | 9:16 (mặc định: 9:16)
⚠️ Lưu ý: Mặc định screen_ratio ở endpoint này là 9:16 (Portrait), khác với các endpoint khác mặc định 16:9.
Request Body
{
  "prompt": "A cat walking in the rain, cinematic",
  "screen_ratio": "16:9"
}
Response (202 Accepted)
{
  "success": true,
  "data": {
    "task_id": "uuid-task",
    "status": "PENDING",
    "poll_url": "https://nathamedia.net/api/veo/video?task_id=uuid-task",
    "download_url": "https://nathamedia.net/api/veo/download/uuid-task",
    "message": "Task queued. Poll poll_url every 10s until status=COMPLETED, then GET download_url for the MP4 file."
  }
}
📌 poll_url: URL đầy đủ để polling trạng thái (sử dụng với Bearer header).
📌 download_url: URL để tải video khi status = COMPLETED (sử dụng với Bearer header).
cURL Example
curl -X POST "https://nathamedia.net/api/veo/generate" \
  -H "Authorization: Bearer {{token}}" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "sunset over ocean", "screen_ratio": "16:9"}'

🔄 Luồng tích hợp hoàn chỉnh (Workflow)

Cách nhanh nhất — Dùng POST /veo/generate:

Bước 1: Gọi POST /api/veo/generate với {"prompt": "...", "screen_ratio": "16:9"}
→ Nhận task_id, poll_url, download_url

Bước 2: Gọi GET {poll_url} mỗi 10 giây (kèm Bearer header)
→ Kiểm tra data.status: PENDING → PROCESSING → COMPLETED

Bước 3: Khi status = COMPLETED → Gọi GET {download_url} (kèm Bearer header, flag -L cho redirect)
→ Nhận file .mp4
Cách chi tiết — Tự quản lý Project:

Bước 1: POST /api/veo/project → tạo project, nhận project_id
Bước 2: POST /api/veo/text-to-video hoặc /image-to-video → gửi task, nhận task_id
Bước 3: GET /api/veo/video?task_id={id} → polling mỗi 10s
Bước 4: GET /api/veo/download/{task_id} → tải file khi COMPLETED

📝 Ví dụ hoàn chỉnh (Python)

import requests
import time

API_KEY = "ak_live_your_key_here"
BASE = "https://nathamedia.net/api"
HEADERS = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# 1. Tạo video (auto-create project)
resp = requests.post(f"{BASE}/veo/generate", headers=HEADERS, json={
    "prompt": "A cat walking in the rain, cinematic lighting",
    "screen_ratio": "16:9",
    "model": "VEO_3.1_FAST"
})
result = resp.json()
task_id = result["data"]["task_id"]
poll_url = result["data"]["poll_url"]
download_url = result["data"]["download_url"]
print(f"✅ Task created: {task_id}")

# 2. Polling status (mỗi 10 giây)
while True:
    status_resp = requests.get(poll_url, headers=HEADERS)
    status_data = status_resp.json()["data"]
    print(f"⏳ Status: {status_data['status']}")

    if status_data["status"] == "COMPLETED":
        print("🎉 Video completed!")
        break
    elif status_data["status"] == "FAILED":
        print(f"❌ Failed: {status_data.get('error')}")
        break

    time.sleep(10)

# 3. Download video
if status_data["status"] == "COMPLETED":
    video_resp = requests.get(download_url, headers=HEADERS, allow_redirects=True)
    with open("output.mp4", "wb") as f:
        f.write(video_resp.content)
    print("📥 Video saved: output.mp4")

⚠️ Mã Lỗi (Error Codes)

HTTP CodeÝ Nghĩa
400Dữ liệu gửi lên không hợp lệ (thiếu field, sai format) — ValidationError
401API Key không hợp lệ hoặc thiếu — AuthenticationError
403Không có quyền truy cập (role/permission không đủ) — ForbiddenError
404Task hoặc Project không tồn tại
422Task đã thất bại (khi gọi download endpoint)
429Quá nhiều request — chờ rồi thử lại — RateLimitError
500Lỗi server nội bộ
502Lỗi từ Google API upstream — UpstreamError
